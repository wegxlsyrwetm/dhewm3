## Overview

dhewm3 is an open-source Doom 3 source port based on id Software's GPL-released id Tech 4 code, bringing id's 2004 horror shooter to modern 64-bit Windows, Linux, and macOS with OpenAL audio featuring EFX environmental reverb, improved controller support, and compatibility fixes. It maintains full compatibility with the Doom 3 mod ecosystem including the Resurrection of Evil expansion.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **dhewm3** delivers the features you need in a clean, intuitive package.

> Official website: [dhewm3.org](https://dhewm3.org)

## Key Features

| Feature | Description |
|---------|-------------|
| **64-Bit Native** | Compiled as a native 64-bit application for all supported operating systems |
| **OpenAL + EFX** | OpenAL audio replaces DirectSound with environmental reverb via EFX |
| **Controller Support** | Full Xbox-style gamepad support with analog look and rumble feedback |
| **Mod Ecosystem** | Compatible with Doom 3 base game, Resurrection of Evil, and community mods |
